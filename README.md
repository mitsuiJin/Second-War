# Second-War
경희대 XSBD - 한국IT직업전문학교 협업 게임 개발 프로젝트

## 프로젝트 개요

언리얼 5 기반 포스트 아포칼립스 1인칭 핵앤슬래시 게임

한국 IT직업전문학교 기획자 6명과 경희대학교 게임 개발 동아리 XSBD 개발자 5명으로 팀 구성

**목표:** 전투 중 플레이어 경험 향상을 위한 UI 시스템 구현

- 킬로그, 데미지 인디케이터, 피격 화면 효과, 타겟팅, HUD, 스킬 UI 등 전투 관련 UI 전반 개발
- 실시간 애니메이션과 이벤트 처리, 생명주기 관리

## 담당 역할 및 주요 기여

### 1. 전투 UI 시스템

**킬로그 시스템**

- 적 처치 시 해골 아이콘 표시
- 타이머 기반 Fade-In/Out 애니메이션 (Scale, Opacity 동시 제어)
- 5초 후 자동 소멸하는 생명주기 관리

**데미지 인디케이터**

- 360도 모든 방향 피격을 원형 UI로 표시
- 삼각함수(Atan2, Sin, Cos) 활용한 정확한 방향 계산
- 근접/원거리 공격 타입별 아이콘 구분
- 플레이어 회전 시에도 정확한 방향 유지
**피격 화면 효과**

- 체력 비율에 따른 Niagara 이펙트 동적 교체 (99-80%, 79-50%, 49-30% 구간별)
- HitFlash/Breathing 애니메이션 충돌 방지
- 타이머 기반 애니메이션 우선순위 제어

**타겟팅 시스템**

- 적 조준 시 크로스헤어 UI 표시
- 단계별 락온 애니메이션 (Ready → Success)
- 각 단계별 색상, 크기, 회전 효과 적용

### 2. 플레이어 HUD

**무기 슬롯 UI**

- 2개 무기 슬롯 간 전환 애니메이션
- 위치 기반 애니메이션 맵핑 (Center/Top)
- 무기 교체 시 부드러운 슬롯 이동 효과

**탄약 표시**

- 현재 탄창/최대 탄창 표시
- 무기 교체 시 자동 업데이트

### 3. 스킬 UI

- 로켓 런처 스킬 시각적 피드백
- 쿨타임 비율에 따른 6단계 텍스처 적용

## 기술적 문제 해결

### 문제 1: 킬로그 UI 소멸 중 크래시

**상황**

해골 이미지 페이드아웃 중 KillLogWidget이 GC로 파괴되면 콜백에서 Access Violation 발생

**원인**

C++ 람다에서 Raw Pointer 캡처로 인한 파괴된 객체 접근

**해결**

1. **TWeakObjectPtr 사용:** 위젯을 약한 참조로 캡처하여 GC 파괴 시 자동으로 nullptr 설정
2. **TSharedPtr로 타이머 관리:** 타이머 핸들을 공유 포인터로 관리하여 안전한 제어
3. **유효성 검사:** 콜백 실행 시 `IsValid()` 검사로 안전성 보장

**결과**

위젯 조기 파괴 시에도 안전하게 처리되며 메모리 접근 오류 원천 차단

### 문제 2: 전투 중 위젯의 반복적 생성/파괴 오버헤드 개선

**상황**

피격마다 CreateWidget/RemoveFromParent 호출로 전투 중 반복적 오버헤드 발생

**원인**

CreateWidget의 높은 메모리/초기화 비용

**해결**

1. **사전 생성:** BeginPlay 시 최대 5개 위젯을 미리 생성하여 Hidden 상태로 대기
2. **재활용 메커니즘:** 풀에서 Hidden 위젯을 찾아 위치/애니메이션 초기화 후 Visible로 전환
3. **반납:** 애니메이션 종료 시 자동으로 Hidden 처리하여 풀로 반납

**결과**

CreateWidget 호출을 BeginPlay 1회로 축소하여 생성/파괴 비용 제거. 확장 가능한 구조 확보

## 개선 방향

- Manager와 Widget의 양방향 참조를 Delegate 패턴으로 전환하여 단방향 의존성으로 개선 예정
